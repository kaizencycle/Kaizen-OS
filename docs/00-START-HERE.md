## 🎓 Core Concepts

### What is Mobius Substrate?

**Mobius Substrate** (formerly Mobius Systems) is the civic-technical base layer built to pass the **Kaizen Turing Test (KTT)**. It combines:

- 🏗️ **DVA Kernel Logic**: Decentralized Verification Architecture
- 💎 **Mobius Integrity Credits (MIC)**: Shard-denominated integrity economy
- 📊 **Mobius Integrity Index (MII)**: Real-time systemic health metric (≥0.95 required)
- 🏛️ **Two-House Governance**: Concord Council (ethics) + TSC (technical)
- 🌱 **UBI**: Universal Basic Integrity distribution
- 🤖 **Sentinel AI**: Distributed governance intelligence

### Key Principles

1. **Intelligence moves. Integrity guides.** — Mobius Principle
2. **We heal as we walk.** — Founder's Seal
3. **Integrity measured. Integrity rewarded.** — MIC Economy
4. **Transparency by default.** — Foundation Governance
