## 1. Objective

Formalize the first constitutional record when a Mobius Agent leaves the controlled Mobius sandbox and begins observing the public internet.

The internet is a pool of claims, artifacts, testimony, and conflicting observations — **not** automatically canonical truth.

The first external EPICON documents observation **conditions** before event-level judgment.

---

## 2. Proposed canonical record

**EPICON-000 — External Reality Boundary**

| Field | Value |
|-------|-------|
| Trigger | First authorized public-internet access |
| Primary finding | Information can travel faster than verification |
| Constitutional finding | The network is a witness pool, not a source of truth |
| Initial verdict | `QUARANTINE` (evidence domain, not per-source falsehood) |
