## 4. Narrative safeguard — five lanes

Public output must distinguish:

| Lane | Label | Example prefix |
|------|-------|----------------|
| What happened | `ESTABLISHED` | "Independently corroborated:" |
| What was claimed | `CLAIM` | "Sources assert:" |
| What was observed | `OBSERVED` | "Mobius observed:" |
| What was inferred | `INFERENCE` | "This suggests (not proven):" |
| What remains unknown | `UNKNOWN` | "Not yet established:" |

**What would change the verdict:** always include when state is `CLARIFY` or `QUARANTINE`.
