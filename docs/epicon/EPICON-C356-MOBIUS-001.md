## Intent

Establish `MOBIUS.md` at the Mobius-Substrate repo root as the single
machine-facing constitutional orientation file for all agents operating
within Mobius Substrate.

Prior state: no unified machine-readable constitutional orientation existed.
Agents cold-starting in any Mobius repo had to traverse multiple docs to
reconstruct: what Mobius is, what it protects, what is forbidden, how agents
must behave, who holds halt authority, and where canonical truth lives.

This document closes that gap with a single dense file that is read by
machines first.

## Scope

Single new file: `MOBIUS.md` (repo root).

**Not touched:** cycle.json, ledger, vault, journals, attestation records,
existing protocol docs, CI workflows, schemas. No existing content mutated.
