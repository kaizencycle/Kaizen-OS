# Dashboard Microcopy

All UI text, tooltips, warnings, and explanations for the Citizen Oversight Dashboard.

**Tone:** Calm, non-accusatory, pattern-focused, explicitly anti-panic. Never "breaking news" energy.

---

## Global Tone Rules

1. **Calm** — No urgency language unless truly urgent
2. **Non-accusatory** — Describe behavior, not intent
3. **Pattern-focused** — Emphasize trends over incidents
4. **Anti-panic** — Explicitly discourage overreaction
5. **Plain language** — No jargon, no acronyms without explanation

---

## MII Status Microcopy

### Stable (🟢)

**Main text:**
> "This system is operating within established integrity thresholds."

**Subtext:**
> "Integrity has remained stable for [X] days."

### Watch (🟡)

**Main text:**
> "Some signals merit attention. No immediate harm detected."

**Subtext:**
> "Review in progress. Updates will appear here."

### Breach (🔴)

**Main text:**
> "Integrity thresholds were exceeded. Review and escalation are in progress."

**Subtext:**
> "Stewards have been notified. See activity log for details."

### Tooltip

> "MII reflects patterns over time, not individual incidents."
