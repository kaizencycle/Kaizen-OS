## Core Principle

> **Understanding is attestable. Agreement is not.**

A learner may understand a lesson perfectly, disagree with Mobius's approach, explain why, and still pass the assessment.

## Runtime Gating

Academy runtime (services, UI, learner records) is gated on OAA Phase D per the OAA Charter. This specification is safe to merge regardless of Phase D status.
