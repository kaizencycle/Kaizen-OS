# Reserve Block Attribution — Custodian Reference, Not Archive Ownership

**Version:** 0.1 · **Cycle:** C-369 · **Status:** PROPOSED

## Canonical rule

> The individual may be attributed to a Reserve Block. The individual does not own the truth preserved inside it.

## Preferred attribution model

```
MIC recognition: 50
Reserve Block attribution: RB-XXXXX
Seal: SXXX
Status: cold-canon verified
Role: contributing custodian
```

Possible meanings:

- Contribution included in a sealed Reserve Block
- MIC recognition backed by sealed constitutional memory
- Reserve access or collateral rights under explicit policy
- Attribution as contributing custodian — not speculative title

## Reserve Blocks must not become

- Transferable NFTs or speculative collectibles
- Privately rewritable archives
- Purchasable status symbols

## Relationship to EVE sharding

EVE may **propose** ethical memory shards for Reserve Block candidacy. EVE may **not** seal, canonize, or rewrite source EPICONs. See [EVE_SHARDING_PROTOCOL.md](../epicon/EVE_SHARDING_PROTOCOL.md).
