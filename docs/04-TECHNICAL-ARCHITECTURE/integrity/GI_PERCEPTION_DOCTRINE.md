# GI Perception Doctrine — Attested Estimate, Not Objective Truth

**Version:** 0.1 · **Cycle:** C-369 · **Status:** PROPOSED

## Canonical rule

**GI (Global Integrity)** is Mobius's current **attested estimate** of federation integrity, based on declared instruments, weights, agents, confidence, and known blind spots.

GI witnesses integrity. GI is not integrity itself.

## Perceptual stack

```
Reality
  → available public and local signals
  → instruments
  → normalization
  → agent interpretation
  → contradiction checks
  → quorum
  → GI estimate
```

## What GI must never be presented as

- Objective truth or total social health
- A perfect measure of morality
- Proof that every component is healthy
- A target to optimize ("reach GI95")
- A direct mint trigger for MIC or Fountain payouts

## Required disclosure

Every published GI state should expose confidence, measured domains, instrument health, source diversity, known blind spots, and weight version. See `gi-perception-manifest.schema.json`.

GI confidence must **degrade** when:

- Instruments disappear or correlate
- APIs fail repeatedly
- Weights change without versioned amendment
- Agents share identical evidence paths
- Domains are underrepresented

## Metric humility

A high score without blind-spot disclosure is a different, false claim. No metric may be acted upon without confidence and blind spots available in the same context.

## Agents and gaming

- Agents must estimate GI honestly
- Agents must never be instructed to "reach GI95"
- Contributors must not receive rewards based purely on GI movement
- Improve reality, not the score
