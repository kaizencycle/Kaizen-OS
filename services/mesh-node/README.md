# Mobius mesh-node (Phase 2 stub)

Express service with `/health` and `/v1/discovery`. Intended to grow into libp2p mesh replication alongside `packages/integrity-core` `CRDTLedger`.

```bash
npm run build --workspace=@mobius/mesh-node
npm start --workspace=@mobius/mesh-node
```

Environment: `PORT` (default 4060).
